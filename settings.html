Character Vector Search
Embedding ソース・Retrieve chunks・Score threshold は標準の Vector Storage 拡張の Data Bank 設定を使用します。

グループチャット

「応答キャラ自身の結果のみ」では、各メンバーの応答時にそのキャラのカードで検索した結果だけが挿入され、他メンバーの結果は混ざりません。 「対象キャラ全員」にすると他メンバー用の資料もヒットし得るため、口調を分けたい場合は「そのキャラ自身」を推奨します。

クエリに使うカードの項目

Embedding モデルの入力上限を超えてエラーになる場合に設定してください。

Injection

{{text}} = 検索結果(応答キャラ分。まとめて挿入時は全員分)、{{name}} = 応答キャラ名。{{char}}, {{user}} などのマクロも使えます。 キャラごとの結果の書式。{{name}} = キャラ名、{{text}} = そのキャラの検索結果。見出しが不要なら {{text}} だけにしてください。
