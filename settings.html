Character Vector Search
Embedding ソース・Retrieve chunks・Score threshold は標準の Vector Storage 拡張の Data Bank 設定を使用します。

グループチャット

毎回の生成で、グループ全員分のキャラカードでそれぞれ検索します。全員分の結果が {{text}} に入り、キャラごとに <character_reference name="キャラ名"> … </character_reference> のブロックで区切られます(1対1ではそのキャラ分のみ)。

クエリに使うカードの項目

Embedding モデルの入力上限を超えてエラーになる場合に設定してください。

Injection

標準と同様に自由に記述できます。{{text}} = 全員分の検索結果(キャラごとのブロックに区切り済み)。{{text}} を書かなかった場合は末尾に付きます。
オフ(既定)の場合、この拡張はベクトル化を一切行わず、標準 Vector Storage 拡張がベクトル化済みのファイルだけを検索します。グループで他メンバーの Character 添付も検索したい場合は、オンにするか、Vector Storage の「Vectorize All」で事前にベクトル化してください。
